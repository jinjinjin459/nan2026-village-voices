01 · CONCEPT

숫자를 읽는 대신,
사람의 말을 읽는 운영 게임

기존 생활 시뮬레이션은 상태창으로 문제를 설명합니다. 마을의 목소리는 시설·관계·사건을 주민 각자의 관점으로 번역해 들려주고, 플레이어가 그 말 사이의 공통점을 추론하게 합니다.

기존 방식

정답을 보여주는 상태창

“공원 부족”, “관계도 25”, “행복도 45”처럼 세계의 수치를 직접 확인하고 최적의 버튼을 누릅니다.

→
우리의 방식

상태를 느끼게 하는 대화

루루의 활기, 모카의 불만, 두부의 걱정을 함께 듣고 마을에 필요한 장소를 스스로 판단합니다.

1
대화주민에게 질문하고
서로 다른 관점을 듣기
2
추론수첩 속 단서에서
공통 문제 발견하기
3
결정효과 수치 없이
시설 하나 선택하기
4
변화코드가 시설·관계·
사건을 확정하기
5
재대화같은 주민의 달라진
반응으로 결과 확인

대화가 인터페이스

AI 대사는 장식이 아니라 플레이에 필요한 정보를 얻는 핵심 수단입니다.

진실은 코드가 관리

AI는 시설·관계·결과를 결정하지 않습니다. 게임 상태를 주민답게 표현합니다.

선택은 세 가지 결과

공원·오락실·잡화점 모두 다른 상태와 후속 대화를 만들어 냅니다.

핵심 메시지　“NPC에게 말을 걸어야만 마을의 진짜 상태를 이해할 수 있다.”

02 · PEOPLE & WORLD

같은 마을, 세 개의 시선

주민은 같은 사실을 알고 있어도 성격·욕구·관계에 따라 다른 말을 고릅니다. 세 사람의 말은 각각 불완전하지만, 함께 들으면 마을의 문제가 보입니다.

햇살 같은 산책가

루루 · 토끼

활발함 · 사교적 · 솔직함
친구들과 몸을 움직이며 함께 놀고 싶다.

“여럿이 오래 머물 만한 곳이 있으면 좋을 텐데!”
마을의 다정한 중재자

두부 · 강아지

다정함 · 눈치가 빠름 · 중재자
세 주민이 다시 자연스럽게 어울리길 바란다.

“같은 곳에 있어도 각자 편할 수 있다면…”
조용한 카페 단골

모카 · 고양이

무뚝뚝함 · 자존심 · 섬세함
사람들과 부딪히지 않고 편하게 쉬고 싶다.

“그냥 바람 쐴 곳이나 있었으면 좋겠어.”
STARTING WORLD

처음부터 존재하는 진실

시설카페 있음 · 나머지 없음
최근 사건붐비는 카페에서 말다툼
루루 ↔ 모카어색하고 좋지 않은 사이
두부의 입장둘 사이를 걱정하는 중재자

행복도와 관계도는 내부적으로 존재하지만 일반 플레이 화면에는 표시하지 않습니다.

CONVERSATION NOTE

정답 대신 남는 단서

  • 루루는 함께 어울릴 곳을 찾는다.
  • 모카는 편히 숨 돌릴 곳이 필요하다.
  • 두부는 자연스럽게 마주칠 계기를 바란다.
“서로 원하는 건 달라도, 모두에게 필요한 공간은 하나일지도 몰라.”

03 · HOW TO PLAY

3분 안에 완성되는
하나의 변화

목표

주민들의 말에서 공통된 문제를 찾고, 마을에 시설 하나를 건설한 뒤 달라진 반응을 확인합니다.

조작

마우스 클릭 또는 터치로 모든 조작을 수행합니다. 추천 질문 버튼과 40자 이내의 직접 질문을 지원합니다.

시작 안내 닫기

“마을의 이야기 듣기”를 누르면 마을 전경이 열립니다.

주민 선택

루루·두부·모카를 눌러 현재 상태가 반영된 이야기를 듣습니다.

질문 이어가기

추천 질문을 누르거나 짧은 질문을 직접 입력합니다.

대화 수첩 확인

이미 들은 단서를 모아 주민들 말의 공통점을 찾습니다.

개발 회의 열기

두 주민 이상과 대화하면 시설 선택이 활성화됩니다.

시설 한 번 선택

효과 수치 없이 공원·오락실·잡화점 중 하나를 결정합니다.

다시 대화하기

달라진 마을에서 주민 두 명 이상의 새로운 반응을 듣습니다.

결과 확인

“변화 돌아보기”에서 Before/After와 선택의 의미를 확인하면 한 판이 끝납니다.

한 번뿐인 마을 결정

04 · BEFORE / AFTER

플레이어의 판단이
주민의 다음 문장을 바꾼다

AI가 결과를 정하는 것이 아닙니다. 시설 버튼을 누르는 순간 게임 코드가 시설·행복·관계·최근 사건을 갱신하고, 다음 대화는 그 새로운 진실을 전달합니다.

BEFORE

모카 · 불만

“카페에 모두 몰리니까 조용할 날이 없잖아. 루루랑 마주치면 또 시끄러워질 것 같고…”

공원 없음 · 루루와 관계가 좋지 않음 · 카페 말다툼 직후

공원
건설
AFTER

모카 · 기쁨

“공원, 생각보다 나쁘지 않더라. 루루도 나무 그늘에선 조금 조용했고… 어제는 꽤 오래 이야기했어.”

공원 생김 · 루루와 관계 개선 · 벤치에서 대화한 새 사건

선택별로 분명하게 갈리는 결과

느티나무 공원루루와 모카의 관계가 크게 개선됩니다. “서로의 속도가 만나는 곳”이라는 긍정적 결과로 이어집니다.
별빛 오락실루루는 즐겁지만 모카는 소음 때문에 떠납니다. 한 주민의 큰 목소리만 들은 결과가 드러납니다.
마을 잡화점세 주민의 생활은 조금 편리해지지만 핵심 관계는 변하지 않습니다. 표면의 불편을 고른 결과입니다.
VISIBLE FEEDBACK

숫자를 숨겨도 변화는 보이게

  • 빈 공터에 선택한 시설이 등장
  • 공원 선택 시 루루·모카가 가까워짐
  • 감정 표정과 대사 내용이 달라짐
  • Before/After 인용문으로 결과 회고
REPLAY VALUE

다른 선택, 다른 관점

세 선택은 성공·부분 성공·문제 미해결의 서로 다른 상태를 만듭니다. 같은 주민에게 같은 질문을 해도 선택한 시설과 최근 사건에 따라 다른 이야기를 들을 수 있습니다.

정답 버튼을 누르는 시연이 아니라, 누구의 말을 어떻게 해석했는지를 되돌아보는 짧은 사회적 추론입니다.

심사자 실행 방법

  1. Chrome, Edge, Safari 등 최신 브라우저에서 플레이 링크를 엽니다.
  2. “마을의 이야기 듣기”를 누릅니다.
  3. 별도 설치·로그인·API 키 입력 없이 전체 핵심 루프를 진행합니다.

권장 화면: 가로 1280px 이상. 모바일·터치 조작도 지원합니다.

로컬 소스 실행

npm ci npm run dev # 제작용 빌드 검증 npm run build npm start

Node.js 20.19 이상 또는 22.12 이상 권장. 환경 변수 없이 실행하면 검증된 안전 대사 모드로 동작합니다.

AI 연결 모드

서버 환경 변수 GEMINI_API_KEY가 설정되고 API가 정상일 때 Gemini 3.6 Flash가 현재 상태를 반영한 대사를 생성합니다. 키는 클라이언트 코드에 포함하지 않습니다.

응답 지연·API 오류·형식 오류 시 시설과 단계에 맞는 검증 대사로 자동 전환되어 플레이가 중단되지 않습니다.
