## 중요한 구현 판단

- AI는 대사·감정·주제만 표현하고 상태 변화 권한이 없다.
- 브라우저가 보낸 관계·사건 문자열은 신뢰하지 않고 서버가 phase/selectedFacility로 scenario truth를 재구성한다.
- 공개 Pages와 Worker는 키를 포함하지 않으며 Workers AI binding을 사용한다. API 실패 시 상태별 fallback으로 완주한다.
- 로컬 `server.mjs`만 선택적으로 `GEMINI_API_KEY`를 읽는다.
- Gemma 4는 기본 reasoning이 짧은 출력 한도를 소모하므로 Worker에서 `enable_thinking:false`와 `max_completion_tokens:512`를 사용한다.
- 모델 JSON은 prompt·parser·서버 validator·브라우저 validator의 경계 안에서만 사용한다.
